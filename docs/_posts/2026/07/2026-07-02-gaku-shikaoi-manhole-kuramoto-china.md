## マンホール概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | ふたマス!!!!!!（アイマス20周年記念マンホール企画） |
| 担当地域 | 北海道河東郡鹿追町 |
| 担当アイドル | 倉本千奈（学園アイドルマスター） |
| デザイン | 然別湖の水中鉄道・ピカ（エゾナキウサギ）・ミヤベイワナ |
| 設置日 | 8月23日（日）11:00〜 |
| お披露目会場 | 道の駅しかおい 特設デッキ |

「ふたマス!!!!!!」は全国各地の自治体とタイアップしてご当地マンホールを設置する20周年記念プロジェクトで、鹿追町は今回新たに参加が決定した自治体の一つ。
